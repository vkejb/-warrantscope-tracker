# Next-session outcome audit v1 (frozen before calculation)

Research-only, SHADOW_ONLY, NO_LIVE_ORDER, actual_orders=0. Input is every first-per-stock-day `EARLY_ENTRY_READY_OBSERVED` row in the existing `raw_signal_comparison_results/all_raw_signals.csv`; retain the original-rule and account-selection labels for subgroup diagnosis. No refitting, filters, or executable P&L.

For horizons 1, 3, and 5, use the nth subsequent session in the existing trading calendar after excluding documented closed-date corrections (2026-10-23, 2026-10-26). Data-source correction after the first audit run: 2026-10-09 was erroneously present in the calendar but was an official market holiday; exclude it as well and preserve the initial run separately. This changes target dates, not any strategy rule or threshold. Verify each archived daily ZIP hash in `shadow_daily_runner/runtime/active_inputs.json`. The current calendar's SHA-256 differs from that manifest's recorded hash; retain actual and expected hashes and mark `CALENDAR_HASH_MISMATCH`, not verified. Treat future target dates as provisional. Price return = (target-session close / signal proxy entry price - 1) * 100. Continuation return = (target close / signal-session close - 1) * 100. Also calculate 0050 close-to-close return on the same dates and individual continuation minus 0050, if all bars exist. Positive means strictly >0; flat is separate. Each row's target date and source prices must be retained.

No later-than-as-of bars. `PENDING` if the target trading session has not occurred; `MISSING_ARCHIVE` if target session occurred but is later than the latest validated daily archive; `MISSING_BAR` if the session is archived but the symbol has no valid close; `COMPLETE` otherwise. Missing 0050 does not invalidate the stock outcome but makes excess return NA. Signal-date bar missing makes continuation NA. Corporate-action adjustment is not established; raw close returns are descriptive, not total returns. Signal entry price is a simulated proxy, not a verified fill. Summary denominator is 365; only COMPLETE rows enter each horizon's return distribution. Same-day correlated signals are not independent trials. No fees, spreads, overnight gap execution, risk, or account capital are simulated.
