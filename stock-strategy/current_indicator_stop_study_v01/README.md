# Current Indicator Stop Study V0.1

研究模式在目前 `HARD_3500_PLUS_MFE_V1_NO_LOSS_RECOVERY` 退場政策上，加上因果式行情確認停損。

固定比較：

- 現行淨損 3,500 元災難停損。
- 虧損進入 -0.25R 後，60秒逐筆方向、60秒大單方向、五檔合計失衡三項中至少兩項反向，且連續兩個30秒成立。
- 上述 -0.25R 條件再要求 LONG 跌破 VWAP／SHORT 突破 VWAP。
- 虧損進入 -0.5R 後才套用相同兩次行情確認。

1R 固定為3,500元淨損風險。所有版本保留3,500元災難停損、MFE_V1、反向訊號、強制出場、費稅與既有滑價代理。

本模組不連接券商、不送單，也不修改 LIVE 策略。
